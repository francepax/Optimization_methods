\subsection{Operation that preserve convexity}
Algebraic operations:
\begin{lemma}
    If $C_1  \text{and}C_2$ are convex, then $C_1 + C_2\doteq \{x+y: x \in C_1, y \in C_2\} $ is convex.\\
    If $C_1  \text{and} C_2$ are convex, then $C_1 - C_2\doteq \{x-y: x \in C_1, y \in C_2\} $ is convex.
\end{lemma}
Topological operations:
\begin{lemma}
    if $C$ is ocnvex then$ cl(C) $is convex.
    if $C$ is ocnvex then$ int(C) $is convex, provided that\\ $int(C)\ne \emptyset $.
\end{lemma}
